WellLife reference-style static website

Files included:
- index.html: Homepage resembling the reference mockup
- category.html: Category listing page with filters and sort
- product.html: Product detail template
- style.css: Responsive styling for all three pages
- script.js: Search, product filters, sort, category title and detail-page behavior

IMPORTANT:
This is a visual/demo starter. Product listings, ratings, claims and links are placeholders. Affiliate buttons are NOT connected to ClickBank. Add only verified product information and your approved ClickBank HopLinks before publishing.

How to update GitHub:
1. Download and extract this ZIP.
2. In your GitHub repository, use Add file > Upload files.
3. Upload all five files into the repository root. When GitHub says files already exist, uploading same-named files will replace them on commit.
4. Commit changes to main.
5. Wait for GitHub Pages to redeploy and refresh the website with Ctrl+Shift+R.

If uploading all files at once feels difficult, update one file at a time in this order: style.css, script.js, index.html, category.html, product.html. Keep file names exactly as shown.

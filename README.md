# WellLife — GitHub Website Starter

A responsive, no-build HTML/CSS/JavaScript starter for a Health & Wellness affiliate marketplace.

## Files
- `index.html` — homepage structure and sample sections
- `style.css` — responsive green/white design
- `script.js` — working sample search, category filters, sorting and demo messages

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository, for example `welllife-website`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

## Before publishing affiliate offers
- Replace the sample product cards with real offers you have reviewed and are allowed to promote.
- Add your own ClickBank HopLinks (or links from another approved affiliate network) to each relevant product button.
- Keep a clear affiliate disclosure visible near affiliate content and on a dedicated disclosure page.
- Do not use invented product ratings, testimonials, medical outcomes, prices or claims.
- Confirm product names, claims, policies and permitted promotional methods against the seller/network's current terms.
- Add Privacy Policy, Terms, Contact and About pages before collecting personal information or email addresses.
- Configure GA4 and Google Tag Manager only after you decide the measurement plan and privacy/consent requirements for your audience.

## Important
This is a starter template, not a complete production website. Search and filters work on the sample cards; newsletter submission and affiliate buttons are demos and do not send/store data or earn commissions. The sample products are fictional placeholders.
